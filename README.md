# ONG proteger

## Sobre o projeto

A ONG Proteger é um projeto acadêmico de desenvolvimento front-end, criado para apresentar ações sociais de apoio à comunidade, com foco no atendimento e na assistência a pessoas idosas.

O site reúne informações sobre a organização, seus projetos sociais e um formulário de cadastro de apoiadores.

## Tecnologias utilizadas

- HTML5: estrutura das páginas.
- CSS3: estilos, layout e adaptação para diferentes tamanhos de tela.
- JavaScript: interatividade, navegação e manipulação do conteúdo.
- Git: controle de versão do projeto.

## Como executar o projeto

1. Baixe ou clone o repositório do projeto.
2. Abra a pasta `exercicio-faculdade` no Visual Studio Code.
3. Utilize uma extensão de servidor local, como o Live Server, para abrir o projeto no navegador.
4. Acesse a página inicial `html/index.html` pelo servidor local para testar a aplicação.

## Acessibilidade

Foram realizados testes de navegação pelo teclado, identificação dos campos do formulário com o Narrador do Windows e verificação de contraste entre algumas combinações de cores.

Também foi adicionada a identificação acessível das mensagens do formulário por meio dos atributos `role="status"` e `aria-live="polite"`, permitindo que leitores de tela anunciem as mensagens de validação.
